# Real NBA rosters for Basketball GM (updated daily)

A [Basketball GM](https://play.basketball-gm.com) league file of the **current real NBA season (2026-27)**, rebuilt every morning after the night's games:
real rosters (injuries, contracts, bios, draft info), ratings derived from real stats, current standings, season stats so far and the remaining real schedule.

**One-click:** [start a new league with today's rosters](https://play.basketball-gm.com/new_league#url=https%3A%2F%2Fraw.githubusercontent.com%2Ftonga43%2Fbbgm-nba-roster%2Fmain%2Fnba-roster-latest.json.gz)

Or in BBGM: New League → Customize → *Enter league file URL* → `https://raw.githubusercontent.com/tonga43/bbgm-nba-roster/main/nba-roster-latest.json.gz`
(uncompressed: `https://raw.githubusercontent.com/tonga43/bbgm-nba-roster/main/nba-roster-latest.json`)

- `latest-changes.md` – what changed in the latest update (trades, signings, injuries, rating moves)
- `changelog.md` – full history

Data: ESPN public API and Basketball-Reference. Ratings are a statistical estimate. Each update is a fresh league; BBGM can't merge it into an existing save.
